# Десктоп-клиент

Клиентское JavaFX-приложение для управления ресурсами и пользователями через HTTP API бэкенда.

## Пользователи и доступ

**Пользователь**:
Учётная запись человека в системе: email, имя, фамилия, роль и флаг активности.
_Avoid_: Клиент, профиль, аккаунт

**Роль**:
Уровень доступа учётной записи: `USER`, `MODER` или `ADMIN`. Старшая роль включает все права младших (`USER < MODER < ADMIN`).
_Avoid_: Права, привилегия

**Гость**:
Неаутентифицированный посетитель без сессии; доступна только страница входа.
_Avoid_: Аноним, незалогиненный пользователь

**Создание пользователя**:
Создание учётной записи администратором через форму пользователя. Саморегистрации в системе нет.
_Avoid_: Регистрация (кроме имён существующих классов `RegisterData`, `RegisterRequest`)

**Блокировка**:
Отключение входа для учётной записи (`enabled=false`): заблокированный пользователь не может аутентифицироваться, запись при этом сохраняется. Новые пользователи всегда создаются активными.
_Avoid_: Деактивация, отключение, удаление

**Удаление пользователя**:
Безвозвратное удаление учётной записи из системы. В отличие от блокировки, запись исчезает полностью.
_Avoid_: Блокировка, деактивация

## Ресурсы и файлы

**Ресурс**:
Смысловая единица хранения: метаданные (`title`, `description`, даты) плюс прикреплённые файлы.
_Avoid_: Документ

**Файл**:
Вложение ресурса: метаданные (`name`, `contentType`, `size`) плюс байты, хранящиеся на сервере.
_Avoid_: Вложение, документ

**Скачивание**:
Сохранение одного файла ресурса в локальный каталог.
_Avoid_: Экспорт (в значении одного файла)

**Экспорт**:
Выгрузка данных наружу: XLSX-таблицы пользователей или ресурсов, либо архив файлов ресурса.
_Avoid_: Скачивание (в значении выгрузки)

## Сервисы и ошибки

**Сервисная ошибка**:
Сообщение для пользователя со статусом ответа; статус `0` означает отсутствие связи с сервером. Контроллер показывает её текст напрямую.
_Avoid_: Ошибка API (деталь транспортного уровня, не термин)

**Проверка ввода**:
Клиентская проверка полей формы до вызова сервиса. Её сообщения — не сервисные ошибки.
_Avoid_: Валидация сервера, сервисная ошибка (в значении проверки полей)
